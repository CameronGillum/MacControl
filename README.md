# ☕ MacControl

MacControl is a modular macOS automation toolkit built around Apple's first-party technologies.

It began as an Amphetamine toggle shortcut and has evolved into a framework for controlling and monitoring a Mac using:

- AppleScript
- Shortcuts
- iCloud Drive
- JSON
- Git

No subscriptions.

No cloud servers.

No external APIs.

Everything runs locally and syncs through Apple's ecosystem.

## Philosophy

MacControl follows a few principles:

- Apple-first
- Privacy-first
- Offline-first
- Modular
- Easy to extend

Every automation should work independently while sharing the same status system.
